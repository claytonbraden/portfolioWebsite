Ticket Exchange Simulation - Object Oriented Programming

Project Description:

Developed a ticket exchange simulation using object-oriented programming principles in Python. The simulation models the buying and selling of tickets in a dynamic market environment. The simulation also allowed user to browse current and past events. The project involved the use of verious OOP concepts and design patterns.

Languages/Specific Libraries::

C++, SQL
