Day Trading Model - Unsupervised Machine Learning

Project Description:

Created a day trading model that uses unsupervised machine learning techniques to analyze historical stock data and identify patterns that can inform trading decisions. The model utilizes clustering algorithms to group similar stock behaviors and make predictions based on these clusters.
