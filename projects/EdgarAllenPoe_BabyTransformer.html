Edgar Allen Poe Text Generator - Baby Transformer (Character Based)

Project Description:

Created a text generator using a baby transformer model based on character-level input to produce text in the style of Edgar Allan Poe.

Languages/Specific Libraries::

Python - Transformers, PyTorch, Hugging Face Datasets
