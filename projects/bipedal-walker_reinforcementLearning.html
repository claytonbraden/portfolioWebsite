BiPedal-Walker - Reinforcement Learning

Project Description:

This project focused on implementing and evaluating reinforcement learning algorithms to train a bipedal robot to walk efficiently in the BipedalWalker-v3 environment from OpenAI Gym. The study compared the performance of Proximal Policy Optimization (PPO) and Soft Actor-Critic (SAC), analyzing their effectiveness in learning stable and efficient locomotion behaviors. Key aspects of the project included robotic state and sensor data processing, control system design, reward function engineering, and neural network architecture development to optimize agent performance.

GitHub Repository: https://github.com/claytonbraden/2DBiPedalWalker_DeepReinforcenemtLearning_CSPB3832

Milestone 1: Environment Setup and Baseline Implementation

Set up the BipedalWalker-v3 environment and implemented a baseline reinforcement learning algorithm (PPO) to establish a performance benchmark.

Milestone 2: Algorithm Comparison and Performance Analysis

Implemented the SAC algorithm and compared its performance against PPO, analyzing learning curves, reward trajectories, and stability of the learned policies.
