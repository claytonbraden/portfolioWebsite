Pickleball Computer Vision - Supervised Machine Learning

Project Description:

Developing a supervised machine learning system for pickleball computer vision, focusing on ball detection and tracking. The project explores CNNs and transfer learning to identify the ball during gameplay.

Languages / Libraries:

Python, OpenCV, YOLOv8

GitHub Repository: pickleballVision

Project Milestones

Milestone 1: Building a 2,000+ Frame Labeled Dataset, Obtained Baseline Results via YOLOv8

Creating a diverse dataset from multiple pickleball matches to train and evaluate ball-detection models. Use YOLOv8 to develop baseline results for performance evaluation.
