Pickleball Computer Vision - Supervised Machine Learning

Project Description:

Developed a supervised machine learning model for computer vision applications in pickleball, focusing on object detection and tracking. Utilized convolutional neural networks (CNNs) and transfer learning techniques to achieve high accuracy in identifying players, paddles, and the ball during gameplay.

Languages/Specific Libraries::

Python - Transformers
