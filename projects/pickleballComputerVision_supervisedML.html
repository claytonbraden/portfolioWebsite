Pickleball Computer Vision - Supervised Machine Learning

Project Description:

Developed a supervised machine learning model for computer vision applications in pickleball, focusing on object detection and tracking. Utilized convolutional neural networks (CNNs) and transfer learning techniques to achieve high accuracy in identifying players, paddles, and the ball during gameplay.

Languages/Specific Libraries::

Python - Transformers

GitHub Repository: https://github.com/claytonbraden/pickleballVision

Milestone 1: Building a 2,000+ Frame Labeled Dataset

Developing a custom frame-labeling tool to annotate pickleball footage from multiple matches. The goal is to build a diverse dataset of 2,000+ labeled frames to train and evaluate computer vision models for ball detection and tracking.

Frame Labeling Demonstration

Demonstration of the custom tool used to label pickleball video frames for supervised learning.
